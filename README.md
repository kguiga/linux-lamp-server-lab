# linux-lamp-server-lab

## Projeto acadêmico desenvolvido na disciplina de Sistemas Operacionais da FGV.

## Objetivo:
Implantar e configurar um ambiente Linux completo com serviços web e banco de dados em máquina virtual.

## Atividades realizadas:
- Instalação de distribuições Linux
- Configuração de Dual Boot
- Atualização de pacotes
- Instalação do Apache
- Instalação do MySQL
- Configuração PHP
- Administração de usuários e permissões
- Compartilhamento de arquivos
- Publicação de páginas HTML
- Configuração de ambiente LAMP

## Tecnologias:
- Linux
- Apache
- MySQL
- PHP
- VirtualBox
- HTML
