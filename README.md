# Linux LAMP Server Lab

Projeto acadêmico desenvolvido na disciplina de Sistemas Operacionais da FGV.


## Objetivo

Implantar e configurar uma infraestrutura web baseada em Linux utilizando máquina virtual, servidor Apache e banco de dados MySQL.


## Arquitetura

VM Linux
├── Apache
├── PHP
└── MySQL


## Atividades Realizadas

- Instalação e configuração do sistema operacional Linux
- Configuração de ambiente Dual Boot
- Atualização e gerenciamento de pacotes
- Instalação e configuração do Apache
- Instalação e administração do MySQL
- Configuração do PHP
- Gerenciamento de usuários e permissões
- Compartilhamento de arquivos
- Publicação de páginas HTML
- Implementação de ambiente LAMP


## Tecnologias

- Linux
- Apache
- MySQL
- PHP
- VirtualBox
- HTML
